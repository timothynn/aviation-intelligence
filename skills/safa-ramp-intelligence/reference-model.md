# SAFA / SACA Reference Model

This skill is based in part on the SAFA Ramp Inspections Guidance Material supplied with this project. It must be treated as a historical/reference source and reconciled against the current EASA legal and procedural framework before production use.

## Core lifecycle

```text
Selection
  -> Preparation
  -> Ramp inspection
  -> Evidence / observations
  -> Finding
  -> Categorisation
  -> Action
  -> Communication
  -> Corrective action
  -> Verification
  -> Closure
```

## Targeting signals

The reference material identifies long-term planning, short-term planning and spot checks. Useful information can include previous inspections, prioritisation information, standard reports, complaints, ATS information, whistleblower information, State oversight concerns and occurrence reports.

## Inspection structure

The historical guidance describes 54 checklist items across operational, cabin/safety, aircraft-condition and cargo areas, with an additional general category for other observations. Limited time may require focused inspection selection.

## Findings and evidence

A finding should reference the applicable standard and retain supporting evidence. Where technical standards are involved, evidence can include technical-log entries and aircraft/manufacturer documentation.

## Follow-up

The reference workflow distinguishes routine notification, written communication for significant/major findings and immediate actions where safety impact requires restrictions or corrective action before flight. Findings can remain open until satisfactory response/evidence or verification is received.

## AI assistance

AI may assist with:

- target briefing
- historical trend analysis
- checklist prioritisation
- evidence indexing
- standard/reference retrieval
- finding text suggestions
- recurrence detection
- follow-up tracking
- report quality checks

AI must not independently impose operational restrictions, ground an aircraft, close a finding, or make an enforcement decision.
