# Roadmap

The project should grow from reusable engineering primitives into a practical aviation AI platform.

## Phase 1 — Foundation

- [ ] Establish aviation domain models
- [ ] Establish Python AI/ML package conventions
- [ ] Establish .NET API conventions
- [ ] Add synthetic aviation data generators
- [ ] Add document ingestion primitives
- [ ] Add baseline evaluation framework

## Phase 2 — Knowledge

- [ ] Regulatory document parsing
- [ ] Requirement extraction
- [ ] Hybrid aviation search
- [ ] Citation-aware RAG
- [ ] Compliance gap analysis
- [ ] Aviation knowledge graph

## Phase 3 — Aviation intelligence

- [ ] Workflow intelligence
- [ ] Inspection assistant
- [ ] Safety/occurrence classification
- [ ] Maintenance anomaly detection
- [ ] Predictive maintenance examples
- [ ] Aviation computer vision examples

## Phase 4 — Agents

- [ ] Aviation assistant
- [ ] Regulatory agent
- [ ] Compliance agent
- [ ] Inspection agent
- [ ] Safety agent
- [ ] Workflow agent
- [ ] Tool permissions and agent audit trail

## Phase 5 — Assurance

- [ ] Aviation-specific benchmark datasets
- [ ] Groundedness evaluation
- [ ] Hallucination evaluation
- [ ] Evidence quality scoring
- [ ] Explainability patterns
- [ ] Human-in-the-loop review patterns
- [ ] AI safety and security guardrails

## Guiding rule

Do not optimize for the number of demos. Optimize for reusable components, reproducible examples, meaningful aviation evaluation and engineering quality.
