# Aviation document sources

The document-intelligence corpus is intentionally built from first-party aviation authority sources.

See:

- `skills/aviation-document-intelligence/source-manifest.yaml`
- `skills/aviation-document-intelligence/CORPUS.md`
- `skills/aviation-document-intelligence/LICENSE-NOTES.md`

The registry is designed to be re-run periodically so the corpus can follow new revisions without treating stale binaries as authoritative.
